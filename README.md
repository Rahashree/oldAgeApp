# Digital Life Assistant for Seniors 👴👵

A web application designed to empower elderly users by simplifying daily digital tasks, medication reminders, emergency contacts, health tracking, and simple navigation.

## 🚀 Features

- **Senior-Friendly UI**: High contrast, large fonts, clear icons, and accessible touch targets.
- **Medication Reminders**: Keep track of daily prescriptions and schedules.
- **Emergency Assistance**: One-tap access to emergency contacts and emergency actions.
- **Health & Daily Care Tracker**: Easy logging for vital signs and health routines.
- **Multi-language Support**: Accessibility-first design for international users.

## 🛠️ Built With

- **React** (Vite)
- **Lucide React** (Icons)
- **CSS3 / Modern Web API**

## 💻 Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/oldAgeApp.git
   cd oldAgeApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
